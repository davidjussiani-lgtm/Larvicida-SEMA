# Larvicida — Site do Mapa

Site simples que incorpora o Google My Maps e exibe um resumo dos dados extraídos.

Como usar

1. Abra `index.html` no seu navegador (ou sirva com um servidor estático).
2. O mapa principal está embutido via iframe. Use o botão "Baixar KML" para obter o arquivo KML público do mapa (se disponível).

Observações

- Os dados presentes em `data/map_summary.json` foram extraídos automaticamente do conteúdo público da página do Google My Maps; algumas coordenadas e atributos completos podem não ter sido acessíveis via scraping. Para exportação completa, abra o mapa no Google My Maps e use "Exportar para KML/KMZ".
